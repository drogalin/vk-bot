# VK AI Bot — автоответчик для сообщества ВКонтакте

Бот отвечает на входящие сообщения в сообществе ВК с помощью ИИ (DeepSeek или любой OpenAI-совместимый API) и опирается на вашу базу знаний (RAG на BM25).

## Возможности

- Приём сообщений через Bots Long Poll API — публичный сервер и SSL не нужны.
- Ответы через DeepSeek или другой OpenAI-совместимый API.
- База знаний: `knowledge.md`, поиск релевантных фрагментов (BM25), без внешних сервисов.
- История диалога по каждому собеседнику, защита от дублей, индикатор «печатает».
- Автопереподключение Long Poll.
- Минимальная веб-панель управления (`panel.py`, только stdlib): вход по паролю, настройки и пополнение базы знаний из файла.

## Быстрый старт

```bash
git clone https://github.com/drogalin/vk-bot.git
cd vk-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните токены и PANEL_PASSWORD
python vk_bot.py
```

## Панель управления

```bash
python panel.py
```

Панель открывается на http://127.0.0.1:8080 и защищена паролем `PANEL_PASSWORD` из `.env` — задайте его до запуска. После входа отображаются поля «Логин», «Пароль», «Токен сообщества», «API-ключ» и загрузка файла базы знаний (`.md` или `.txt`). Кнопка «Сохранить и пополнить» пишет доступы в `.env` и дописывает содержимое загруженного файла в `knowledge.md`. Панель слушает только localhost — не выставляйте её в интернет без пароля и HTTPS.

## Настройка

Все параметры — в `.env` (см. `.env.example`). Токен сообщества ВК выдаётся в настройках сообщества с правом «Сообщения сообщества»; включите Long Poll API и событие «Входящие сообщения».

## Структура проекта

```plaintext

├── panel.py           # мини-панель управления (только stdlib)

├── .env.example
└── .gitignore
```
